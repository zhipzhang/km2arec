Installation
============

**km2arec** supports Python >= 3.8.

## Installing with `pip`

**km2arec** is available [on PyPI](https://pypi.org/project/km2arec/). Just run

```bash
pip install km2arec
```

## Installing from source

To install **km2arec** from source, first clone [the repository](https://github.com/zhipzhang/km2arec):

```bash
git clone https://github.com/zhipzhang/km2arec.git
cd km2arec
```

Then run

```bash
pip install -e .
```
